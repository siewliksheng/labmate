# Example traces

Exported, reviewed runs that back up claims in the top-level README —
evidence, not just a demo GIF. Populated starting M1, once tracing exists.

Before committing a trace here:
1. Confirm the underlying data is synthetic/public (see top-level README
   "Data") — nothing from a real lab.
2. Scrub the export of API keys / internal identifiers.
3. Name it descriptively: `safety-escalation-triggered.json`,
   `router-v1-misroute.json` (the failure traces that motivated later
   redesigns are the most valuable ones to keep — don't only keep the wins).
