# Example traces

Exported, reviewed runs that back up the claims in the top-level README —
evidence, not just a demo GIF.

Before committing a trace here:
1. Confirm the source report is synthetic (Synthea) or that you're permitted
   to redistribute the specific MIMIC-CXR excerpt (generally: don't — prefer
   synthetic examples for anything public-facing).
2. Scrub the export of API keys / internal identifiers.
3. Name it descriptively: `critical-finding-flagged.json`,
   `tool-schema-v1-failure.json` (the failure traces that motivated the v2
   redesign are the most valuable ones — keep them).

Link each one from the main README where it's relevant, don't just dump them
here unreferenced.
